## ⚡ Quickstart Guide

Get the project running locally in **less than 2 minutes**:

```bash
# 1️⃣ Clone repository
git clone https://github.com/your-org/india-technology-services.git

# 2️⃣ Move into directory
cd india-technology-services

# 3️⃣ Install dependencies
npm install

# 4️⃣ Launch dev server
npm run dev
```

Visit [`http://localhost:3000`](http://localhost:3000) in your browser.
